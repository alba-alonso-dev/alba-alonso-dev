## 👩‍💻 Sobre mí

Desarrollo **herramientas para videojuegos** con Unity/C# y **aplicaciones web full-stack** con .NET y Angular.

- 🧰 Me especializo en **tools programming**, arquitecturas **data-driven** y sistemas **editor-friendly**.
- 🤖 Me interesa especialmente la **IA aplicada a videojuegos**: comportamiento de agentes, sistemas procedurales y toma de decisiones.
- 🌱 Ahora mismo: generación procedural de mazmorras y visualización de Behavior Trees en Unity.
- 🤝 Abierta a colaborar en proyectos de **game tools**, **IA para juegos** o **web full-stack**.

> 🇬🇧 *Game tools & full-stack developer based in Spain. I build Unity/C# editor tools, data-driven gameplay systems and .NET + Angular web apps, with a special interest in game AI and procedural generation.*
